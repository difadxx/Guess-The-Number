Консольная игра "Угадай число" на Python

Описание проекта:
Мой игровой проект на Python. Компьютер загадывает случайное число от 1 до 100, а задача игрока - угадать его за минимальное количество ходов, используя логические подсказки от системы.

Как это работает:
1. Старт игры. С помощью функции randint из модуля random компьютер выбирает секретное число, а переменная для подсчета попыток сбрасывается в ноль.
2. Игровой цикл. Программа запускает бесконечный цикл while, который постоянно запрашивает варианты ответов у пользователя. Каждое введенное число увеличивает счетчик попыток на единицу.
3. Логические подсказки. Через цепочку условий if, elif и else программа сравнивает число игрока с секретным и дает подсказку: Загаданное число БОЛЬШЕ или Загаданное число МЕНЬШЕ.
4. Финал. Как только игрок угадывает число, программа хвалит пользователя, выводит точное число его попыток и останавливает цикл командой break.

Что использовалось в коде:
- Ввод и вывод данных (команды input и print).
- Генерация случайных целых чисел с помощью модуля random.
- Управление логикой игры через бесконечный цикл while и принудительный выход из него через break.
- Проверка условий через ветвление if, elif и else.
